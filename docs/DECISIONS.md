| 8 | Enum-like columns are `text` narrowed by TypeScript, not Postgres enums | Sets like `failure_class` grow as we learn how runs fail; a Postgres enum needs a migration per value while a narrowed text column keeps compile-time safety and lets the set evolve. |
| 9 | Append-only tables are enforced by a trigger *and* a role REVOKE | The REVOKE is the production control but is ignored for superusers, which is how dev connects; the trigger fires for every role, so the guarantee holds in both. |
| 10 | The directory repository is deliberately not tenant-scoped | §5.3's cross-tenant learning requires that one tenant's bounce suppress an address for all tenants; making it scoped would defeat the compounding effect that is the product's moat. |
