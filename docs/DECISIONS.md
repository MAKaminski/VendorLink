| 7 | The 50 seeded PM companies are synthetic, on `.example` domains | This product sends real email to the addresses in this table; seeding real company names against invented domains and contacts would ship fabricated records about identifiable businesses and mail them on the first Batch Connect. See `docs/replace-seed-directory.md`. |
| 8 | Enum-like columns are `text` narrowed by TypeScript, not Postgres enums | Sets like `failure_class` grow as we learn how runs fail; a Postgres enum needs a migration per value while a narrowed text column keeps compile-time safety and lets the set evolve. |
| 9 | Append-only tables are enforced by a trigger *and* a role REVOKE | The REVOKE is the production control but is ignored for superusers, which is how dev connects; the trigger fires for every role, so the guarantee holds in both. |
| 10 | The directory repository is deliberately not tenant-scoped | §5.3's cross-tenant learning requires that one tenant's bounce suppress an address for all tenants; making it scoped would defeat the compounding effect that is the product's moat. |
| 11 | Passwords hashed with scrypt from Node core rather than Argon2id | Argon2 needs a native module; scrypt is memory-hard, in the standard library, and needs no build step in an image that already carries Chromium. OWASP parameters (N=2^15, r=8, p=1). |
| 12 | `@vendorlink/core` has a `./domain` subpath for client components | The default barrel re-exports providers that reach for `node:fs`/`node:dns`; importing it from a client component fails the build, so the pure domain is a separate, browser-safe entry. |
| 13 | Sign-in returns the same error for an unknown address as for a wrong password | Distinguishing them turns the login form into an account-enumeration oracle. |
| 14 | Each test database is migrated directly rather than cloned from a template | Vitest runs projects in parallel and two workers racing to build a shared template collide on `CREATE DATABASE`; direct migration costs a few hundred ms and needs no coordination. |
| 15 | The golden set runs with the LLM **disabled** | The gate is meant to measure the deterministic rubric that S4 exists to protect; letting the model contribute would measure the model instead, and the rubric could rot behind a passing number. |
| 16 | S4 is skipped entirely when a tier-1 inbox is already found | An LLM call adds latency and cost for an answer the rubric already has. Measured on the golden set: 0 model calls needed for 50/50 accuracy. |
| 17 | A failed S4 call degrades to the deterministic answer rather than failing the run | The rubric already has an answer; losing the model should reduce certainty, not availability. |
| 18 | Ranking breaks ties on the *unclamped* score | Clamping is right for confidence (135 is not "more than certain") but flattens rank: a tier-1 `vendors@` and a tier-3 `procurement@` on the same vendor page both hit 100, and alphabetical tiebreak put procurement first. |
| 19 | Person/title extraction is bounded to the address's own HTML block | A symmetric text window on a flattened staff listing attributed the person above's title to the person below, which then outranked the correct contact. |
| 20 | Only a *hard* bounce suppresses globally; a soft bounce does not | A soft bounce is a full mailbox or a transient failure. Suppressing on those would discard good addresses for every tenant on the strength of a temporary condition. |
| 21 | A rate-limited send leaves the task `queued` with a `nextRetryAt`, not `failed` | It is deferred, not rejected — failing it would make the operator re-click work the governor intends to do itself. |
| 22 | A run whose only contacts are suppressed reports `send_blocked_suppressed`, not `no_contact_found` | `bestContact` filters suppressed addresses out, which made "it stopped working" indistinguishable from "we never found anyone". Those need different operator responses. |
| 23 | Webhooks reject unsigned requests even when no secret is configured | The bounce webhook mutates global suppression state; accepting unauthenticated calls would make it a denial-of-service lever against every tenant. |
| 24 | `wrong_department` has no deterministic classifier rule | Its phrasings overlap with ordinary replies ("please contact us with any questions"), and a false positive applies a −40 penalty to a good address for every tenant. |
| 25 | An unreviewed platform defaults to `assisted_only`, never to unattended | Failing open would mean the first unrecognized credentialing platform receives automated registration attempts against terms nobody has read. |
| 26 | A form posting to the page's own origin is classified `custom` (allowed); a form posting to an unrecognized third party is `null` (assisted) | Submitting a PM's own form is the vendor's own action on their own behalf. An unknown third-party host is a platform whose terms we have not read. |
| 27 | Currency is written to forms as a plain decimal, with no symbol or separators | Form validators commonly reject `$` and `,`; `1000000.00` is accepted everywhere `$1,000,000.00` is. The symbol form stays in the email template, where a human reads it. |
| 28 | Run confidence is the *minimum* over required fields, not the mean | Averaging hides the single field that is about to be filled wrongly, which is the only field that matters. |
| 29 | Parked runs are filled before parking | The assisted lane's promise is ~30 seconds per item; that only holds if the operator opens a form that is already 95% complete. |
| 30 | The worker Dockerfile and fly.toml are committed but never built or deployed | No Fly credentials exist in this environment. Committing them makes the deployment shape reviewable; they are marked unverified rather than presented as working. |
| 31 | The Needs-Attention resume page ships review-and-correct, not live co-browsing | §7.3 describes an embedded live browser session. The correction loop — the part that makes the assisted lane compound rather than stay manual — is implemented and tested; the CDP screencast transport is not. Flagged rather than implied. |
| 32 | An operator's field correction is stored at confidence 1.0 with `mappedBy: 'operator'` | It is the only mapping source verified by a human against the live form, so it should outrank both the rules table and the model on the next run. |
